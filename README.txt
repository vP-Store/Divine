DATEIEN IN DIESEM PAKET:

  icons/          → App-Icons in allen Größen
  README.txt      → Diese Datei

INSTALLATION (Hosting):
────────────────────────
Option 1 — GitHub Pages (kostenlos):
  1. GitHub Account erstellen
  2. Neues Repository erstellen
  3. Alle Dateien hochladen
  4. Settings → Pages → Branch: main → Save
  5. URL: https://deinname.github.io/journal/

Option 2 — Netlify (kostenlos, einfacher):
  1. netlify.com → Sign up
  2. "Add new site" → "Deploy manually"
  3. Den gesamten Ordner auf die Seite ziehen
  4. Fertig! Du bekommst eine .netlify.app URL

Option 3 — Beliebiger Webserver:
  Alle Dateien in den Root-Ordner deines Servers kopieren.
  WICHTIG: Muss HTTPS sein (kein HTTP) für PWA-Features!

APP INSTALLIEREN (auf dem Handy):
──────────────────────────────────
Android (Chrome):
  → Beim Öffnen erscheint automatisch ein Banner "App installieren"
  → Oder: Menü (⋮) → "Zum Startbildschirm hinzufügen"

iPhone/iPad (Safari):
  → Tippe auf das Teilen-Symbol (□↑ unten in Safari)
  → "Zum Home-Bildschirm" antippen
  → "Hinzufügen" bestätigen
